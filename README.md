# Personal Website

This repository contains the planning and, as work progresses, the source code for a personal website with a blog.

## Project status

Planning is underway. The agreed framework is **Astro**, configured to generate a static site. The pages, blog authoring workflow, design, and production hosting setup are still being decided.

## Planned hosting

The current hosting direction is the owner's Ubuntu home server, using Docker and the existing Cloudflare Tunnel. Tunnel routing and production deployment have not been configured yet.
